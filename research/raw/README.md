# Raw Evidence (intermediate)

One subfolder per agent: `raw/<agent-slug>/`. Files named `YYYY-MM-DD-<topic-slug>.md`
using `../templates/raw-notes.md`. Models/data may be `.csv` alongside.

Nothing here is a conclusion. Never cite raw notes from `docs/`; cite
`docs/RESEARCH.md` sections instead.

Large or copyrighted captures (PDFs, screenshots, page dumps) go in
`raw/<agent>/_local/`, which is gitignored. Tracked notes must still record URL and
access date so the source can be re-retrieved.

Do not delete raw notes that a report cites.
